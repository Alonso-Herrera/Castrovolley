CastroVolley es una plataforma diseñada para la gestión, organización y seguimiento de equipos y actividades de voleibol. Su objetivo es centralizar la información del club, facilitando el control de jugadores, entrenamientos, pagos, estadísticas y eventos deportivos en una interfaz moderna e intuitiva.

Características principales
📋 Gestión de jugadores y equipos.
📅 Administración de entrenamientos y eventos.
📱 Diseño adaptable para dispositivos móviles y escritorio.
🔍 Consulta rápida de información relevante del club.
Objetivo

Brindar una herramienta digital que optimice la administración de clubes y equipos de voleibol, mejorando la organización interna y la experiencia de jugadores, entrenadores y directivos.

Tecnologías utilizadas
HTML5
CSS3
JavaScript
